# 🌱 Prakriti Harvest

**Prakriti Harvest** is an intelligent and sustainable farming assistance platform developed for the **Smart India Hackathon (SIH)**. It focuses on optimizing fertilizer usage to ensure **higher crop yield**, **soil health**, and **eco-friendly agriculture**. The system empowers farmers with data-driven recommendations tailored to their crop, soil type, and local environmental conditions.

---

## 🚀 Project Objective

To build a **Sustainable Fertilizer Usage Optimizer** that:
- Recommends the right type and amount of fertilizer.
- Uses soil health data, crop type, and environmental factors.
- Aims to increase yield while reducing environmental impact and cost.

---

## 🌾 Key Features

- 📊 **Smart Fertilizer Recommendation System**  
  Inputs: Soil type, Crop type, pH level, rainfall, temperature, and more.  
  Output: Fertilizer type, quantity, and schedule.

- 🧠 **AI-Powered Insights**  
  Uses machine learning to predict best practices for maximizing yield.

- 🧪 **Soil and Weather Analyzer**  
  Integrates APIs for real-time weather data and provides soil-type-based analysis.

- 📱 **Farmer-Friendly UI**  
  Easy-to-use interface, available in local languages for broader adoption.

- 📍 **Geo-Location Integration**  
  Auto-detects location and fetches relevant data like rainfall, temperature, etc.

---

## 🧰 Tech Stack

- **Frontend:** HTML, CSS, JavaScript (with responsiveness)
- **Backend:** Python (Flask)
- **Machine Learning:** scikit-learn, pandas, numpy
- **Database:** SQLite / MySQL
- **APIs:** OpenWeatherMap API, soil datasets
- **Hosting:** Localhost (development) / Deployable on Render, Heroku, or PythonAnywhere

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Sumit2910/prakriti-harvest.git
   cd prakriti-harvest
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Flask app**
   ```bash
   python app.py
   ```

4. **Access the app**
   Open your browser and go to `http://127.0.0.1:5000/`
